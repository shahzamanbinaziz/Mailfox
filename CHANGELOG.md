# Changelog

## [0.1.0] — Phase 0 · Foundation & brand — 2026-11-15

### Added

- **Monorepo**: pnpm workspaces + Turborepo; strict TypeScript everywhere; shared ESLint (flat) + Prettier.
- **Brand kit** (`/brand`): "Envelope Fox" mark — the envelope flap is the fox's face — in colour, mono and
  dark variants; full logo with outlined Plus Jakarta Sans wordmark; favicon set (ICO 16/32/48, SVG, apple-touch,
  192/512, maskable) + web manifest + PNG email logos, all generated by `brand/scripts/*.mjs` with `sharp`.
- **Design tokens** (`packages/ui`): 7 colour scales (50–950, OKLCH), light/dark semantic tokens, WCAG AA verified
  in tests; generated Tailwind v4 `tokens.css`.
- **Brand components**: `Logo`, `LogoMark`, `LogoIntro` (ears pop → flap folds → swoosh, 1.3s),
  `FoxSpinner`, `Skeleton`, `FoxSkeletonCard`, `CampaignSent` (envelope flies off with a fox-tail trail),
  empty states for campaigns / contacts / mailboxes. All respect `prefers-reduced-motion`.
  CSS-animated SVG versions in `brand/animations`.
- **Brand guide page** at `/brand`: logo variants with downloads, clear space, colour scales (click to copy),
  contrast table, typography, live motion previews, empty states, rendered email layout.
- **Database** (`packages/db`): Prisma 7 schema with every core model (User, Workspace, Membership, Session,
  Invitation, Domain, Mailbox, MailboxPool, Contact, CustomField, List, Tag, Segment, Suppression, SignupForm,
  Template, Campaign, CampaignAudience, CampaignVariant, Send, Link, Event, Automation, AutomationStep,
  AutomationEnrollment, ApiKey, Webhook, WebhookDelivery, AuditLog, AiUsage, AiMessage, Notification),
  initial migration and an idempotent demo seed (admin, 2 mailboxes + pool, 500 contacts with consent,
  lists, tags, segments, suppressions, 3 templates, 1 sent campaign with ~1,500 events, 1 scheduled A/B campaign).
- **Core** (`packages/core`): zod env loader, AES-256-GCM secret encryption, HMAC link signing, roles, queue names.
- **Email** (`packages/email`): branded MJML layout with compliant footer, MJML → HTML + plain text,
  personalization engine (`{{first_name|"there"}}`, `{{#if}}…{{else}}…{{/if}}`, HTML-escaping), 3 starter templates.
- **Apps**: web (home with live demo stats, `/api/health`), worker (BullMQ heartbeat, `/health`, graceful
  shutdown), tracker (Fastify, `/health`).
- **Infra**: multi-stage `Dockerfile`, `docker-compose.yml` (Postgres 17, Redis 7, Mailpit, migrate, web,
  worker, tracker), Codespaces devcontainer, GitHub Actions CI (format, lint, typecheck, test, build, migrate +
  seed against real Postgres) and GHCR image publishing.

### Verified

- 32/32 Turborepo tasks pass (lint, typecheck, test, build) — 63 unit tests.
- Migration applied and seed run against Postgres 16; seed re-run is a no-op.
- web, worker and tracker start from their build output and report healthy; worker heartbeat reaches Redis.
